`cad`, `CadWorkspace.tsx`, and `cad.ts` are the CAD workspace screen and implementation modules. `screen: 'cad'` selects the CAD workspace screen. The implementation lives in `web/src/components/CadWorkspace.tsx`, and `web/src/cad.ts` contains validation, conversation-keyed state, and approval checks.

`CadWorkspace` is the Hermes-facing CAD panel. Its durable key is `profile:storedId` (or `new:<profile>` before a chat is stored); `runtimeId` is only the live RPC binding. `getCadWorkspace` returns one state object per key and updates a resumed runtime without creating another session; `rebindCadWorkspace` moves a newly-created chat from its draft key and rejects destination collisions. The panel supports Back to chat and Close, preserves the original bytes in an in-memory `CadSession`, and leaves CRS unknown until the user enters one. CAD file selection accepts only `.dwg` and `.dxf`; `validateCadFile` checks a DWG `AC10xx` header or a DXF SECTION/EOF signature before calling the existing `attachFile` chunk upload path. Native file attachments use `uploadChunk`, `finishUpload`, and best-effort `abortUpload` for cleanup when a chunk or finish operation fails; these bridge methods are key-wrapped in `secure-bridge.ts`. The MVP panel does not expose a mutation button until a concrete operation is wired; the core `CadSession` requires a matching approval request for add/delete/undo and rejects direct use through the package barrel.
