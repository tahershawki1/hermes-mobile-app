`cad`, `CadWorkspace.tsx`, and `cad.ts` are the CAD workspace screen and implementation modules. `screen: 'cad'` selects the CAD workspace screen. The implementation lives in `web/src/components/CadWorkspace.tsx`, and `web/src/cad.ts` contains validation, conversation-keyed state, and approval checks.

`CadWorkspace` is the Hermes-facing CAD panel. Its durable key is `profile:storedId` (or `new:<profile>` before a chat is stored); `runtimeId` is only the live RPC binding. `getCadWorkspace` returns one state object per key and updates a resumed runtime without creating another session. The panel supports Back to chat and Close, records original and working-copy names, and leaves CRS unknown until the user enters one. CAD file selection accepts only `.dwg` and `.dxf`; `validateCadFile` checks a DWG `AC10xx` header or a DXF SECTION/EOF signature before calling the existing `attachFile` chunk upload path. Mutations are represented by `requestCadMutation` and are not applied until `approveCadMutation` receives the matching current revision; stale approvals are rejected.
