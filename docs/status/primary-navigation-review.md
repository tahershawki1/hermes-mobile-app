# Hermes Mobile primary navigation

**State:** Phase 1 is accepted. Home, Sessions, Work, Knowledge and More are in place, the chat stays mounted across navigation, and local Hermes uses the existing Termux integration. The drawing workspace and its dedicated attachments and dependencies are removed; general attachment protections and cleanup are retained. User feedback fixes (blue navigation accent and closing the drawer with a left swipe) are implemented and browser-checked. Remaining interface polish is for large screens and tablets.

**Next:** Review the updated local preview APK on a phone and, if available, a tablet. Start or resume a chat, then check Home → Continue chat, Work, Knowledge, More, the drawer gestures, light/dark themes, and the large-screen Canvas controls. Keep Hermes Go feature work paused until this UI review is complete.

**Needs a real phone:** Start or resume a chat, type a draft, visit Knowledge and Work, and return through Home → Continue chat. Open the Add and Commands menus and check that ordinary photos and files can be attached. Verify Home → Status details, More → System, notification deep links and Back from a subpage. Try the dark and light themes and an Arabic system locale. Check that voice, Canvas, the drawer and approvals still work.
