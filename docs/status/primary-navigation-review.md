# Hermes Mobile primary navigation

**State:** Phase 1 adds Home, Sessions, Work, Knowledge and More. The chat stays mounted across navigation and local Hermes uses the existing Termux integration. The drawing workspace and its dedicated attachments and dependencies are removed. General attachment protections and cleanup are retained.

**Next:** Review the preview APK on the phase PR. Its package is separate from the daily app. User approval of this version is required before merging the phase or starting phase 2.

**Needs a real phone:** Start or resume a chat, type a draft, visit Knowledge and Work, and return through Home → Continue chat. Open the Add and Commands menus and check that ordinary photos and files can be attached. Verify Home → Status details, More → System, notification deep links and Back from a subpage. Try the dark and light themes and an Arabic system locale. Check that voice, Canvas, the drawer and approvals still work.
